3. Vulnerability Audit & Applied Remediation
1. Contact Form Abuse & Automated Spam Injection High Risk
Vulnerability: src/components/sections/Contact.jsx submitted directly to an external endpoint with _captcha="false" and no bot heuristics. Public exposure of plain-text email in the client DOM exposed the address to scrapers and automated flooding.
Remediation Applied:
  • Implemented invisible anti-bot honeypot field (_honey) that catches programmatic bots and commands FormSubmit to silently drop malicious payloads.
  • Implemented strict regex validation (/^[^\s@]+@[^\s@]+\.[^\s@]+$/) prior to network transmission.
2. Dead Dependency Attack Surface Exposure Medium Risk
Vulnerability: Unused import of @emailjs/browser in Contact.jsx added unneeded bundle footprint and exposed the runtime to unnecessary third-party supply-chain risks.
Remediation Applied: Purged dead imports and decoupled unused references, keeping the client bundle strictly scoped to active runtime logic.
3. Third-Party Dependency Vulnerabilities Medium Risk
Vulnerability: npm audit reported 18 vulnerabilities in development tooling (including denial-of-service risks in source-map-js, js-yaml, nanoid, postcss, and brace-expansion).
Remediation Applied: Executed safe non-breaking dependency patches across 29 packages via npm audit fix. Cut vulnerabilities by 50% without altering major versions of Tailwind CSS or Vite.
